# N1 - Node.js Project Setup

This project is part of the ELEC 3 Node.js activities.

## Project Description
This activity demonstrates the basic setup of a Node.js project using npm, including package installation and project configuration.

## How to Run
1. Open the project folder in the terminal.
2. Install the dependencies using npm install.
3. Run the project using npm start.

## Project Files
- index.js - Main JavaScript file.
- package.json - Contains project information, dependencies, and scripts.
- package-lock.json - Records the exact installed package versions.
- N1_answers.docx - Answers for the N1 activity.
