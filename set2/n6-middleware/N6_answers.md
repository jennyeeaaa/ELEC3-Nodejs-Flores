## Answers

1. Middleware is a function that runs before the server processes a request.
2. It helps the server handle requests before sending a response to the client.
3. In this activity, I used a Logger Middleware to show the method, URL, and date and time of every request in the terminal.
4. I also used another middleware to set the response content type to JSON.
5. I used next() so the request could continue to the next middleware or route handler.
6. The request-response cycle starts when the client sends a request to the server. The server processes the request and sends back a response.
7. I learned that middleware makes the API easier to manage and helps me monitor the requests sent to my server.
